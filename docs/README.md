# Documentation Index

Documentation for `@dcyfr/ai-graphql`, an Apollo Server 4 template. For installation and a quick start, see the [root README](../README.md).

## Reference

- [API.md](API.md): API reference covering the GraphQL schema, type definitions, resolvers, custom scalars, and authentication and authorization.

## Design and development

- [SCHEMA_DESIGN.md](SCHEMA_DESIGN.md): schema design practices, including schema-first versus code-first, type design, query, mutation, and subscription design, and error handling.
- [TESTING.md](TESTING.md): testing GraphQL APIs with Vitest, covering strategy, setup, unit, integration, and end-to-end tests, and testing subscriptions.
- [PERFORMANCE.md](PERFORMANCE.md): performance optimization, including the N+1 problem, the DataLoader pattern, query complexity, caching, database optimization, and response compression.

## Security

- [SECURITY.md](SECURITY.md): the security policy, including the OWASP Top 10 for GraphQL, additional security measures, a security checklist, and how to report an issue.

## Operations

- [DEPLOYMENT.md](DEPLOYMENT.md): deployment guide covering platforms, Docker, Kubernetes, serverless, a production checklist, and monitoring and observability.
